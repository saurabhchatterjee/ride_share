# ride_share

Phase 1: Build a Simple Monolithic Version

Objective: Get a working end-to-end MVP.

Build a single service that handles:
1. User Registration & Authentication
2. Drivers Registering Their Location
3. Riders Requesting a Ride
4. Matching Riders to Drivers (Naive logic, e.g., nearest driver)
5. Trip Status Updates (Started, Completed)
